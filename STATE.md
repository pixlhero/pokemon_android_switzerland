# Pokémon Android Switzerland — Project State
Last updated: 2026-03-24

## Goal
Find out why several Pokémon mobile games are available on iOS in Switzerland but not on Android (Google Play), and get this fixed.

## Possible Reasons for the Block
- Google Play requires explicit opt-in per country (unlike App Store)
- Regulatory uncertainty in Switzerland
- Small market size / low priority
- Administrative inertia
- Different publishing pipelines per platform
